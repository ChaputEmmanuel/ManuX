\subsection{Les buffers réseau}

   Le buffer réseau est l'outil de base pour faire circuler les
données dans le système réseau. Lorsqu'une trame est reçue sur une
interface, par exemple, un buffer réseau est créé qui contient les
données de cette trame, et c'est ce même buffer qui sera échangé entre
les différentes couches protocolaires, de sorte à ne pas recopier à
chaque fois les données.
